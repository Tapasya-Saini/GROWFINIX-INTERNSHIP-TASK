# TASK-1 Real Estate Pricing Dashboard
Tech Stack: SQL, Power BI

## Overview
Analyzed real estate pricing trends based on neighborhood, square_footage and distance_to_school.

## Dashboard Visuals
1. Slicer - Neighborhood
2. Slicer - Square Footage (Range)
3. Slicer - Distance to School (Range)
4. Bar Chart - Average of Price by Neighborhood
5. Scatter Chart - Price vs Square Footage

## Insights
- Downtown has highest average price
- Price increases with square_footage
- Properties closer to school have higher price
